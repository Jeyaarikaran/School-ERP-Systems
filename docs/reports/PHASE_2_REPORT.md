# Phase 2 Report: Database Core, Auth, RBAC, and Multi-tenancy

## 1. What was built
- **Core Models:** Implemented SQLAlchemy models for Tenant (School, Settings), Identity (User, Session, Token, 2FA), RBAC (Roles, Permissions), and Audit mechanisms. 
- **RBAC Catalog:** Defined 60 distinct permissions across 13 modules in `app/permissions/catalog.py` serving as the single source of truth.
- **Role Templates:** Implemented system role templates (`super_admin`, `school_admin`, `teacher`, etc.) with wildcard expansion for dynamic permission assignments.
- **Tenant Isolation:** Created `TenantRepository` base class which explicitly scopes all operations to a provided `school_id` and overrides writes to ensure tenant safety.
- **Audit Service:** Created transactional, append-only `AuditService` with automatic redaction of sensitive fields (passwords, tokens).
- **Auth Dependencies:** Built FastAPI dependencies for JWT bearer token validation, Redis-backed revocation checking, and permission enforcement.

## 4. ADRs Added & Deviations
- **ADR-011: Platform Session Mode vs DB Role.** Chosen: Shared DB role with explicit `SET LOCAL app.current_school_id` per transaction context, rather than separate DB users, to minimize connection pool overhead while keeping RLS tight.
- **ADR-012: Token Signing Algorithm (RS256).** Explicitly configured in `.env.example` to allow future frontend verification without exposing symmetric secrets.
- **ADR-013: Deferred Google OAuth.** Identity models allow nullable passwords for external providers, but actual Google OAuth implementation is pushed to Phase 8.

## 5. Known Limitations and Risks
- **Environment Constraint:** The automated agent was unable to execute terminal commands (like `alembic revision --autogenerate`, `uv run pytest`) due to a missing PowerShell binary path in the execution environment. Migrations must be generated by the developer running `make migrate` locally.
- **Frontend Hydration:** Next.js and Flutter shells require interactive instantiation (`npx create-next-app`, `flutter create`) which were bypassed.
